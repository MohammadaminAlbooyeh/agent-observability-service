# API Reference

Placeholder for the API reference documentation.

## Endpoints

- `POST /traces/trace` — Ingest a single span
- `POST /traces/batch` — Bulk ingest spans
- `GET /traces` — List traces
- `GET /traces/{trace_id}` — Get a trace with span tree
- `GET /metrics/latency` — Latency percentiles
- `GET /metrics/cost` — Cost summary
- `GET /metrics/error-rate` — Error rate
- `GET /comparisons/{version_a}/{version_b}` — Compare versions
- `POST /alerts` — Create alert rule
- `GET /projects` — List projects
